启用后，默认网络请求、套餐查询、本机 CloakBrowser 和新建 Roxy 环境使用此节点。停用后恢复原有代理配置。任务结束后再切换节点。

1. 导入订阅

支持 Clash / Mihomo YAML、JSON 以及常见 URI / Base64 订阅。推荐选择 Clash / Mihomo 格式。

2. 选择节点

首次使用：导入订阅 → 保存节点选择 → 启用项目代理 → 测试出口 IP。节点不会自动轮换。

使用说明

双击项目的一键启动 BAT，已启用的节点会自动恢复。首次导入需要能连接订阅服务器；也可以在已有节点启用后，通过该节点刷新订阅。

本机 Roxy 请新建环境。远程浏览器或复用的 Roxy 环境需要另行配置其网络；项目入口只监听本机。

订阅链接和节点凭据保存在本机 run/mihomo/，该目录已排除 Git 提交。请妥善保管这个目录。
